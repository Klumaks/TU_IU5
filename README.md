##лекция 1
###Управление технических систем 
**Техническая система** - это искусственно созданная система для удовлетворения технических потребностей.
Это процесс воздействия на объект (объект управления) для достижения поставленных целей.
**Теория управления** - фундаментальная, тк изучает общие закономерности для широкого круга явлений, независимых от назначение и физической природы ОУ.
В качестве ОУ могут выступать **технические системы**, **производственные процессы**, **экономические процессы** вплоть до **человеческого организма**.
**Результаты основания тау** (теория автоматического управления) является способность специалиста разработать: ТЗ, разработать оптимальный алгоритм управления. **Оптимальный** - если математически обоснован: должен быть разработан функционал, учитывающий наиболее важные параметры для решения поставленной задачи. Экстремумы в заданных условиях, в которых функционируют. Не локальный, а глобальный, обусловленный областью.

###Этапы разработки систем автоматического управления:
1. **Изучение** объекта управления оу, разработка его мат модели.
   Математическое описание закономерности, которые ищут взаимосвязь поведения различных параметров управления между собой.
   Система уравнений, если речь о динамике (изменение в динамике). ТУ важна динамика, поэтому уравнения диффуры.
   **Виды мат моделей динамики:** система дифф уравнений (СДУ), если динамика 1 дифф уравнение н-ого порядка, то с помощью метода переменных состояния его преобразуют в **систему первого порядка**. Далее **матричный вид** из СДУ для удобства    реализации. **Дискретный режим** из непрерывного в дискретный. **Линейный** - x+y+z = 0, если входящие переменные имеют только первый порядок и никаких нелинейных функций. Если динамика объекта описывается линейными уравнениями, то такая     система **линейна**.Ту считается линейноЙ, если и только все переменные и их производные *линейны?*.
   **Стационарный и не стационарный**: система считается **стационарной**, если её динамика описывается дифф уравнениями с постоянным во времени коэффициентами. 
   Диву частных производных, не от одного параметра, а от нескольких.

   **ИИ** - подаются воздействия и изучаются реакции системы. 

   **Основные сигналы:**
   **Входные они же управляющие**, те сигналы, которые создаются пользователем или разработчикам в соответсвии с алгоритмом управления
